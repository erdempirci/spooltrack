# SpoolTrack v0.6

## Yeni çalışma akışı

Üretim mühendisi:

1. Projeyi seçer.
2. Zone veya Block seçer.
3. O konumdaki sistemi seçer.
4. SPOOL sekmesinde durumları günceller.
5. ISO sekmesinde otomatik ilerlemeyi görür.

## Excel yükleme

- `IZOMETRI_YUKLEME_SABLONU.xlsx`
- `SPOOL_YUKLEME_SABLONU.xlsx`

İzometri Excel'i önce, spool Excel'i daha sonra yüklenmelidir.

## Windows kurulumu

1. ZIP'i tamamen klasöre çıkarın.
2. `windows_kurulum.bat`
3. `windows_baslat.bat`

Adres: http://127.0.0.1:8502
